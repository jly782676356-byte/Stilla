# Stilla（中文说明）

Stilla 是给 Claude Code 用的额度悬浮窗（Windows）。这个文件夹是**英文界面版**的源码和文档，它的主页是英文的：[README.md](README.md)。

同一个 [Releases](https://github.com/jly782676356-byte/Stilla/releases) 页面里有两种界面语言的安装包（0.2.0）：

- `Stilla-Setup-0.2.0-zh.exe` / `Stilla-0.2.0-portable-zh.zip`：**中文界面**
- `Stilla-Setup-0.2.0-en.exe` / `Stilla-0.2.0-portable-en.zip`：**英文界面**

两种界面语言的功能完全相同，只是界面文字不同。**完整的中文说明在仓库根目录**：[README.zh-CN.md](../README.zh-CN.md)（介绍、安装、常见问题）、[使用说明](../docs/USAGE.md)、[隐私说明](../PRIVACY.md)，文档里的菜单名都是中文界面的。

> Stilla 是独立的社区项目，不是 Anthropic 出品，也没有得到 Anthropic 的认可或支持。"Claude" 是 Anthropic, PBC 的商标。
