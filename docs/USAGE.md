# Stilla 使用说明（0.1.1）

## 悬浮窗

- 拖动窗口任意位置移动；拖边缘 / 四个角调整大小（位置和大小会记住）。
- 右上角「刷新」立即刷新，「×」缩到托盘（程序继续运行）；托盘图标双击显示 / 隐藏，托盘菜单里的「退出」才真正结束。
- 右键菜单：
  - **立即刷新**
  - **额度数据来源**：只用状态栏 / 在线查询（实验性）/ 自动（**默认**：状态栏优先，没有新数据时才在线查询，且要先经你同意，见 README）；设置 / 撤销 Claude Code 状态栏
  - **Claude 数据目录**：看现在读了哪些目录；添加目录…；重新检测；清除手动添加的目录
  - **背景透明度 / 文字透明度**：两个滑块互不影响。背景最低也留一点点不透明度，不然鼠标会穿过去、窗口拖不动
  - **记录用量到日志**（默认开）
  - **显示用量统计**（默认勾选）：详细模式，带用量面板；取消勾选 = 简洁模式，只看额度。和紧凑卡下面的切换按钮是同一个开关
  - **时间标签设置…**：勾选面板里要显示的时间标签
  - **显示 DeepSeek 估价行**（默认关）：面板最下面一行，"如果这些 token 用 DeepSeek 闲时价要花多少"，纯粹是个估算
  - **账号与订阅**
  - **界面风格**（16 种）/ **黑白切换** / **始终置顶**
  - **设置…**：见下面「设置窗口」
  - **退出**
- 快捷键（程序运行时全局生效，被别的程序占用就注册不上，用菜单即可）：`Ctrl+Alt+B` 纸色 ↔ 墨底，`Ctrl+Alt+N` 下一个风格。
- 圆环 / 数字的颜色：60% 以下一般色，60–85% 橙，85% 以上红（部分风格用别的方式表示）。
- 底部那行：`状态栏 · 12:34:56` = 数据时间；`已 N 分钟没更新` = 状态栏数据太旧（Claude Code 没在运行）；`未收到状态栏数据` = 还没配置或还没收到过。

## 设置窗口

右键菜单 / 托盘菜单 →「设置…」，或点 Stilla 标志右边的小红点。

- **更新**
  - 「每次启动时自动检查更新」（默认勾选）：启动约 4 秒后向 GitHub 问一次最新版本号。
  - 「检查更新」：马上查一次，结果显示在上面那行。
  - 「前往更新页面」：在默认浏览器里打开最新 Release 页面（有新版本时红字提示）。不会自动下载 / 安装。
  - 有新版本时，**每个紧凑卡的 Stilla 标志 / 标题右边会出现一个红点**（各风格位置略有不同），托盘提示里也有 ● 标记，并且每个新版本只弹一次托盘气泡。更新到新版本后红点自己消失。
- **支持这个项目 → 捐赠…**：打开项目 README 里的「支持这个项目」一节（GitHub Sponsors、微信、支付宝）。
- **关于**：版本号、声明、「打开数据文件夹」。

## 简洁模式 / 详细模式

默认是**详细模式**：上面是额度紧凑卡，下面是用量面板，打开就能看到全部核心功能。紧凑卡正下方有一个小按钮：

- 详细模式里写着「▴ 收起，只看额度」：点一下，窗口缩成**简洁模式**（只有额度，窗口更小、更窄，也不再读会话文件）；
- 简洁模式里写着「▾ 展开详细统计」：点一下回到详细模式。

按钮在两种模式下位置不变，所有 16 种风格通用；右键菜单里的「显示用量统计」是同一个开关。选择会记在 `settings.txt`（`usage=`），下次启动保持。

## 用量面板

详细模式里就有（或右键 → 显示用量统计）。窗口会变宽；超出屏幕右边会自动往左移。最小尺寸：简洁模式 240 ×（风格高度 + 22），详细模式 420 ×（风格高度 + 22 + 196）；其中 22 是切换栏。

- **时间标签**（默认显示 6 个，最多可选 11 个）：5 分钟、15 分钟、30 分钟、1 小时、3 小时、本 5 小时、上 5 小时（实时统计）；今天、昨天、本周、自定义（读日志）。点标签切换。
  - 「本 5 小时」以额度的 5 小时重置时间为终点往前推 5 小时；拿不到重置时间时按最近 5 小时滚动。
- **五个视图**（表头右边的按钮）：
  - **会话**：每个会话一行：缓存剩余、输入、输出、缓存写入、缓存读取。正在写入的排最上面，缓存没过期的其次。点一行打开明细窗口（缓存命中率、最近 300 条消息、复制会话 ID、打开会话记录文件）。
  - **模型**：一个会话一行，行尾是它用的模型和思考档位标签；点行首的 ▸ 展开该会话下每个「模型 × 档位」的明细。
  - **对比**：所有会话合在一起，每个「模型 + 档位」一行，带"每百万 token 消耗的额度是最便宜那行的几倍"。
  - **档位**：按思考强度（low … max，开 Ultracode 的叫 ultra，快速模式加 +fast）汇总。
  - **订阅**：每个账号一行：本期用量（按官方标价折算的 API 等价金额）、月费、回本倍数、续费日期。
- 列宽可以拖分隔线；点会话名旁边的"其他 N 个"展开全部。
- 缓存剩余 = 这个会话最近一次读写缓存后，缓存还剩多久过期（大多数是 1 小时有效期）。过期后下一条消息要把整个上下文重新写一遍缓存，比续上贵很多。

## 额度换算（可选，需要 Python）

额度消耗 ≈ 按官方价格折算的美元数 × 每美元消耗的额度百分点。系数由 `scripts\quota_fit.py` 用你自己的额度快照和用量日志反推（每小时在后台跑一次，低优先级），按"账号:计划"分开拟合。数据不够（需要几天、跨多个 5 小时窗口）时显示「—」，数字前面的「≈」表示是按官方价格推算的、没有实测。

这些数字是**估算**，不是账单。额度读数是整数百分比，同一账号在网页 / 手机 / 别的电脑上用掉的额度本机记录不到。

## 账号与订阅

- 自动识别当前登录的账号和套餐（读 `.credentials.json` 里的组织 ID / 套餐，和 `.claude.json` 里的账号信息，**只存打码邮箱**）；换账号时自动切换，托盘弹提示。
- 可以给账号起名字、填月费、订阅开始日期（算"回本"和续费日，续费前 3 天托盘提醒）。入口：右键 → 账号与订阅，或点紧凑卡右上角的账号小标签（部分风格没有这个标签）。

## 文件放哪

见 [PRIVACY.md](../PRIVACY.md)。便携模式：`Stilla.exe` 旁放一个空文件 `portable.txt`。环境变量 `STILLA_HOME` 可以指定别的位置。

## 命令行参数

- `Stilla.exe --demo`：演示模式（假额度，设置放在临时文件夹，不碰真实设置，不检查更新），截图 / 测试用。
- `Stilla.Statusline.exe [--quiet] [--chain "命令" | --chain-file 文件]`：给 Claude Code 的 `statusLine` 用。排查问题：设环境变量 `STILLA_DEBUG=1`，错误会写到 stderr。
