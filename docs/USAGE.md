## 悬浮窗

- 拖动窗口任意位置移动；拖边缘 / 四个角调整大小（位置和大小会记住）。
- 右上角「刷新」立即刷新，「×」缩到托盘（程序继续运行）；托盘图标双击显示 / 隐藏，托盘菜单里的「退出」才真正结束。
- 右键菜单（按顺序）：
  - **立即刷新**
  - **额度数据来源**：只用状态栏 / 在线查询（实验性）/ 自动（**默认**：状态栏优先，没有新数据时才在线查询，且要先经你同意，见 README）；设置 / 撤销 Claude Code 状态栏
  - **Claude 数据目录**：看现在读了哪些目录；添加目录…；重新检测；清除手动添加的目录；打开 Stilla 数据文件夹
  - **背景透明度 / 文字透明度**：两个滑块互不影响。背景最低也留一点点不透明度，不然鼠标会穿过去、窗口拖不动
  - **记录用量到日志**（默认开）
  - **缓存快过期时系统提醒**（默认开；面板关着也会约每 15 秒读一次会话记录）
  - **显示用量统计**（默认勾选）：详细模式，带用量面板；取消勾选 = 简洁模式，只看额度。和紧凑卡下面的切换按钮是同一个开关
  - **时间标签设置…**：勾选面板里要显示的时间标签
  - **功能与显示设置…**、**调度策略**、**估算自检详情…**、**周报**、**暂停后台读取（打游戏用）**、**悬停说明（鼠标停一会儿显示解释）**、**邮件提醒…**：0.2.0 新增，分别见下面各节
  - **账号与订阅**
  - **界面风格**（16 种）/ **黑白切换** / **始终置顶**
  - **设置…**：见下面「设置窗口」
  - **退出**
- 托盘菜单：显示 / 隐藏、黑白切换、立即刷新、暂停后台读取、设置…、退出。
- 快捷键（程序运行时全局生效，被别的程序占用就注册不上，用菜单即可）：`Ctrl+Alt+B` 纸色 ↔ 墨底，`Ctrl+Alt+N` 下一个风格。
- 圆环 / 数字的颜色：60% 以下一般色，60–85% 橙，85% 以上红（部分风格用别的方式表示）。
- 底部那行：`状态栏 · 12:34:56` = 数据时间；`已 N 分钟没更新` = 状态栏数据太旧（Claude Code 没在运行）；`未收到状态栏数据` = 还没配置或还没收到过。
- 0.1.x 里右键菜单的「显示 DeepSeek 估价行」挪走了：现在在「功能与显示设置…」→「其他显示内容」里（默认不显示；0.1.x 里打开过的升级后保持打开）。

## 设置窗口

右键菜单 / 托盘菜单 →「设置…」，或点 Stilla 标志右边的小红点。

- **更新**
  - 「每次启动时自动检查更新」（默认勾选）：启动约 4 秒后向 GitHub 问一次最新版本号。
  - 「检查更新」：马上查一次，结果显示在上面那行。
  - 「前往更新页面」：在默认浏览器里打开最新 Release 页面（有新版本时红字提示）。不会自动下载 / 安装。
  - 有新版本时，**每个紧凑卡的 Stilla 标志 / 标题右边会出现一个红点**（各风格位置略有不同），托盘提示里也有 ● 标记，并且每个新版本只弹一次托盘气泡。更新到新版本后红点自己消失。
- **支持这个项目 → 捐赠…**：打开项目 README 里的「支持这个项目」一节（GitHub Sponsors、微信、支付宝）。
- **关于**：版本号、声明、「打开数据文件夹」。

## 简洁模式 / 详细模式

默认是**详细模式**：上面是额度紧凑卡，下面是用量面板，打开就能看到全部核心功能。紧凑卡正下方有一个小按钮：

- 详细模式里写着「▴ 收起，只看额度」：点一下，窗口缩成**简洁模式**（只有额度，窗口更小、更窄，用量面板不再读会话文件，见下面的说明）；
- 简洁模式里写着「▾ 展开详细统计」：点一下回到详细模式。

按钮在两种模式下位置不变，所有 16 种风格通用；右键菜单里的「显示用量统计」是同一个开关。选择会记在 `settings.txt`（`usage=`），下次启动保持。

> 简洁模式下，只要「缓存快过期时系统提醒」还开着（默认开），Stilla 仍会每隔十几秒读一次会话记录新增的部分，用来跟踪缓存。想让它完全不读会话文件：关掉「显示用量统计」，同时取消「缓存快过期时系统提醒」和「记录用量到日志」（后者每分钟读一次新增内容，写进 `logs\`）。

## 用量面板

详细模式里就有（或右键 → 显示用量统计）。窗口会变宽；超出屏幕右边会自动往左移。默认宽度 600（基础单位，随显示缩放），最窄 520；简洁模式最窄 240。

- **时间标签**（默认显示 6 个，最多可选 11 个）：5 分钟、15 分钟、30 分钟、1 小时、3 小时、本 5 小时、上 5 小时（实时统计）；今天、昨天、本周、自定义（读日志）。点标签切换，默认停在「15 分钟」。
  - 「本 5 小时」以额度的 5 小时重置时间为终点往前推 5 小时；拿不到重置时间时按最近 5 小时滚动。
  - 显示哪些标签：右键 → 时间标签设置…，或点标签条右边的「⋮」（见后面）。
- **六个视图**（表头右边的按钮；哪些显示由「功能与显示设置…」决定）：
  - **会话**：每个会话一行：状态灯和名字、缓存剩余、速度、占用、输入、输出、缓存写入、缓存读取（「输入」这一列默认隐藏，见「三档调度」）。正在写入的排最上面，缓存没过期的其次，过期的往下；同一档里最近用过的在前。点一行打开明细窗口（缓存命中率、最近 300 条消息、复制会话 ID、打开会话记录文件）。
  - **模型**：一个会话一行，行尾是它用的模型和思考档位标签；点一行弹出详情小窗，见「模型视图：点会话看明细」。
  - **对比**：所有会话合在一起，每个「模型 + 档位」一行，带"每百万 token 消耗的额度是最便宜那行的几倍"。**0.1.x 里单独的「档位」视图并进了这里**。
  - **订阅**：每个账号一行：本期用量（按官方标价折算的 API 等价金额）、月费、回本倍数、续费日期；最下面三行是订阅周期、本期 API 等价金额、每周额度预测（按近 12 小时内的额度读数推算，会不会在重置前用完）。
  - **API**：见「API 视图」。**推荐档默认不显示**。
  - **趋势**：见「趋势视图」。
- 列宽可以拖分隔线；点会话名旁边的"其他 N 个"展开全部（放不下时用滚轮翻页）；拖「合计」上面那条分隔线（中间有三个小点）可以调行距，双击恢复。
- 「合计」行：当前时间标签里所有行的合计。会话视图里「缓存剩余 / 速度 / 占用」三列不是按时间标签算的，见各自的说明。
- 缓存剩余 = 这个会话最近一次读写缓存后，缓存还剩多久过期（有效期 5 分钟或 1 小时，看这个会话最近写缓存用的是哪种）。过期后下一条消息要把整个上下文重新写一遍缓存，比续上贵很多。

## 会话状态灯与缓存提醒

会话视图里，每个会话行最左边有一个小圆点，「缓存剩余」那一列的文字也用同一个颜色：

| 颜色 | 意思 |
|---|---|
| 绿 | **运行中**：Claude Code 报告它在忙，或最近 60 秒内会话记录里有新内容。缓存随每次请求自动续期，不会过期 |
| 蓝 | **等你处理**：Claude Code 在等你（权限确认 / 提问 / 计划审批等）。它既没在跑，也不是做完了；缓存还在倒数，文字写「等你 m:ss」 |
| 白（常规字色） | 缓存还剩 30 ~ 60 分钟 |
| 黄 | 还剩 10 ~ 30 分钟 |
| 红 | 还剩 10 分钟以内 |
| 灰 | 已过期，或没有缓存 |

越接近过期越黄、越红，是想让你趁缓存还在时发一条消息续上，不用付重新载入的钱。

- **状态从哪来**：绿 / 蓝来自 Claude Code 自己写的 `<Claude 数据目录>\sessions\<pid>.json`（`status` 字段，约每 2 秒重读一次，只读；进程已经不在的文件不算）。这个文件的格式 Claude Code 没有公开文档，将来可能变；读不到时「运行中」仍按"最近 60 秒有新记录"判断，但「等你处理」就看不到了。
- **紧凑卡 / 托盘上的汇总**：紧凑卡上账号小标签左边的小圆点、托盘图标右下角的小点，显示的是所有会话里最要紧的那个状态；托盘提示里会写「红N 黄N 绿N 蓝N」，各有几个会话。
- **系统通知**：缓存剩余**刚刚掉到**提前量以内时，弹一条系统通知（托盘气泡），最多列 3 个会话：标题、还剩几分钟、上下文大小，以及（有价格表时）"过期后重新载入约 $X（续上约 $Y）"。
  - 开关：右键 →「缓存快过期时系统提醒」（默认开），对应 `settings.txt` 的 `alert=`。
  - 提前量：点标签条右边的「⋮」→ 提醒设置 → 缓存快过期时系统提醒的提前量 → 剩 5 / 10 / 15 / 20 / 30 分钟时（默认 10），对应 `alertmin=`。
  - 只在这几种情况才通知：要「亲眼看到」它从提前量以外掉进来（刚启动时已经低于的不补通知）；这个会话的缓存有效期不短于 30 分钟（有效期 5 分钟的会话几乎一直是红的，通知了也没意义）；上下文不少于 5 万 token；会话当前没在运行。暂停后台读取时不通知。
- **额度触顶预警**：5 小时 / 每周额度用到某个百分比时通知一次（每个窗口一次）。「⋮」→ 提醒设置 → 额度触顶预警：关闭 / 用到 70% / 80% / 90% / 95% 时，默认 90%，对应 `limitwarn=`（0 = 关）。

## 跳转到会话所在的窗口

会话视图里，每个会话名右边有一个 **↗**。点它，Stilla 把这个会话所在的窗口切到前台：

- **VS Code 扩展里开的会话**：按会话所在的文件夹名，在所有 VS Code 窗口里找对应的那个（先试会话工作目录的最后一级，再往上最多 3 级；优先找标题里正好有一段是这个名字的，VS Code 的标题格式是 `文件 - 文件夹名 - Visual Studio Code`，找不到再退一步找标题里包含这个名字的，太短的名字不算），切到前台；然后打开 `vscode://anthropic.claude-code/open?session=<会话 ID>`，让 Claude Code 扩展在这个窗口里回到这个会话。开着别的 VS Code 窗口、但没找到对应的那个时，会话会在当前最前面的 VS Code 窗口里打开，并弹一条通知说明；一个 VS Code 窗口都没有时没有通知，`vscode://` 地址直接交给 Windows 去处理。
  - **只认进程名以 `Code` 开头的窗口，也就是 VS Code 和 VS Code Insiders**。Cursor、VSCodium、Windsurf 的窗口不会被匹配（VS Code 标题同步支持它们，但跳转不支持）。
- **终端里开的会话**：顺着 Claude Code 进程的父进程往上，找到第一个有窗口的（Windows Terminal / 控制台窗口），切到前台。**Windows Terminal 里有多个标签时，只能切到窗口，选不了标签。**

说明：

- 这是靠窗口标题里的文件夹名匹配的，所以多个窗口打开同名文件夹时可能切错；`vscode://…` 这个地址由 Claude Code 扩展处理，扩展改了就可能失效。出错时会弹通知（"跳转失败：…"）。
- 开关：「功能与显示设置…」→ 其他显示内容 →「会话行名字右边的 ↗ 跳转」（推荐、全开档默认开，精简档不显示）。
- 只在你点 ↗ 的那一刻才会枚举窗口标题和进程，平时不做。

## 邮件提醒（可选）

缓存快过期时，除了系统通知，还可以让 Stilla 发一封邮件给你自己（人不在电脑前的时候）。**默认关闭，也不经过任何第三方服务器**：你自己填一个 SMTP 服务器（Gmail、Outlook、QQ 邮箱或者别的），Stilla 直接连它发信。

入口（三处是同一个窗口）：右键 →「邮件提醒…」；点标签条右边的「⋮」→ 提醒设置 → 邮件提醒…；会话视图表头的「@」按钮（启用并配置好之后，按钮上会显示勾选了几个会话）。

对话框里要填：

- **启用邮件提醒**：勾上才会发信。
- **邮箱设置**：预设（自定义 / Gmail / Outlook / Hotmail / QQ 邮箱 这几项，选了会填好服务器地址、587 端口和加密选项）、服务器、端口、「STARTTLS / SSL 加密」（默认勾选，别取消）、用户名、密码、发件人（不填 = 用户名）、收件人（多个收件人用逗号、分号或空格隔开，全角的 `，`、`；` 也行）。Gmail / Outlook / QQ 要用「应用专用密码 / 授权码」，不是登录密码；端口用 587（STARTTLS）——465 是「直接 SSL」，这里用的发信组件不支持，通常只会一直超时（填了 465 会先弹警告）。取消勾选加密时（发给本机的除外），在启用提醒并点「确定」、或点「发送测试邮件」时会弹警告：密码和邮件内容会以明文在网络上传输。
- **发送测试邮件**：用上面的设置马上发一封固定内容的测试邮件，结果显示在对话框里。
- **勾选会话**：勾选要提醒的会话，在「剩几分钟时提醒」里填分钟数（1 ~ 600，可以填多个，如 `30,10`；分隔符可以是逗号、分号、空格、斜杠 `/` 和顿号 `、`，全角的 `，`、`；` 也行）；「默认提前」是勾选时自动填的值。

发信规则：

- 要同时满足：已启用、邮箱设置完整（服务器、用户名、密码、收件人）、至少勾选了一个会话、没有暂停后台读取。
- 勾选的会话缓存剩余**刚好掉到**设定的分钟数以内时发一封；每个缓存周期里每个分钟数只发一封。会话在运行中（缓存自动续期）不发；刚启动 / 刚勾选时已经低于的不补发。
- 缓存有效期是 5 分钟的会话，填大于等于 5 的分钟数永远不会触发（否则它每回复一次就发一封）。
- 保险丝：1 小时内最多发 30 封（含测试邮件），再多就先不发，防止哪里出了问题把邮箱刷爆。
- 发送失败会弹一条托盘通知（30 分钟内最多一条），对话框里能看到最近一次发送的结果。

**信里有什么**（完整的，没有别的内容）：

- 标题：`【Claude】「<会话标题，超过 22 个字符的截断并加…>」缓存还剩 N 分钟`
- 正文：会话标题（完整）、缓存还剩约几分钟及过期的时刻、当前状态（在等你处理 / 空闲）、上下文大小和缓存有效期、（有价格表时）重新载入的估算费用、账号编号和套餐名（例如 `B · Pro`）、发信时间，最后两句固定的说明。
- 不含对话内容、不含项目路径、不含登录令牌和登录邮箱。会话标题可能透露你在做什么：它会经过你的 SMTP 服务器和收件邮箱，请按这个来判断要不要用（会话还没有标题时，标题位置是「项目文件夹名 · 会话 ID 的前几位」）。

**密码怎么存**：写在 `%APPDATA%\Stilla\mail.txt`（便携模式在 `data\` 里），用 Windows DPAPI 加密（只有这台电脑上、同一个 Windows 账户能解开），并且和「服务器 + 用户名」绑在一起：文件被拷到别的电脑 / 账户、或者有人改了文件里的服务器 / 用户名，密码就解不开，需要重新输入；在对话框里改服务器或用户名而不重输密码，Stilla 会要求你重新输入，旧密码不会被悄悄发给新的服务器。同一个文件里的服务器、用户名、发件人、收件人和勾选会话的标题是明文。

## 速度、占用和触顶预测

会话视图里有两列：

- **速度·15m**：这个会话近 N 分钟消耗额度的速度。左边是 5 小时额度，右边是每周额度，单位都是「额度百分点 / 小时」。例：`30 / 3.97` = 照这个强度，每小时用掉 30% 的 5 小时额度、3.97% 的每周额度。
- **占用·15m**：这个会话在近 N 分钟里一共占用了多少额度（不除窗口），同样左边 5 小时、右边每周，单位是百分点。占用 ÷ 窗口小时数 = 速度。

通用规则：

- **统计窗口**默认近 15 分钟，两列共用。点表头的「速度」或「占用」文字，选 5 分钟 … 48 小时，或者「自定义…」（1 ~ 2880 分钟）；「⋮」→ 速度统计窗口 里也能选。保存在 `settings.txt` 的 `speedwin=`（分钟）。表头右边的小三角是排序，不是选窗口。
- **灰色**数字 = 这个会话在窗口里已经闲下来（没有消耗，或缓存过期），显示的是它最后一次活跃时、同样长度窗口里的数；只供参考，不计入合计。
- **「≈」** = 额度系数是按套餐倍率推算的（这个账号 / 套餐的数据还不够实测），可能差好几倍。**「—」** = 没有数据，或当前账号还没有额度换算系数。
- 窗口超过 3 小时、以及灰色数字，需要读日志里最近 8 天的记录：「功能与显示设置…」里的「速度历史读取」要开着（推荐、全开档默认开）。
- 速度、占用、触顶预测、API 等价金额都是用「额度换算表」算的（见后面「额度换算」），**这张表由可选的 Python 脚本生成**。没装 Python 或数据还不够时，这几项显示「—」，其余功能不受影响。

**触顶预测**：会话视图里「合计」行下面的一行。假设接下来一直保持合计行的速度，5 小时额度和每周额度各还能撑多久，例如：

> 按近 15 分钟速度 · 5h 约 2.5 小时后触顶（早于重置 1.2 小时）· 周 约 5.4 天后触顶（重置前不会）

红色（含「早于重置 …」）= 照这个速度会在重置前用完；「重置前不会」= 到重置时还用不完；「没有消耗」= 近这段时间没用。这只是外推，窗口很短时波动很大，想要更稳的预测就把统计窗口改长一点（15 ~ 60 分钟）。开关：「功能与显示设置…」→ 其他显示内容 →「合计行下面的触顶预测」（默认开）。

订阅视图最下面另有一行「每周额度预测」，用的是近 12 小时内的额度读数本身，不依赖额度换算表。

## 排序和导出

**排序**：会话、模型、对比三个视图，点列头排序。第一次点：降序（时间 = 最新在前，用量 = 大的在前；对比视图的名字列是 A → Z）；再点一次反过来；第三次恢复默认顺序。每个视图各记各的（`sort0=`、`sort1=`、`sort2=`）。

**导出**：点标签条右边的「⋮」→ 导出当前时间标签的数据：

- 「会话表」和「模型 × 档位明细」，各有两种方式：**复制到剪贴板**（制表符分隔，直接粘贴到 Excel）和**保存为 CSV…**（UTF-8 带 BOM，Excel 能直接打开；保存对话框默认在 `%APPDATA%\Stilla\logs\导出\`，保存到哪里由你选）。
- 会话表的列：会话、会话 ID、缓存状态、缓存剩余（分钟）、5h 速度、周速度、占用 5h、占用周、输入、输出、缓存写、缓存读、成本（美元）、成本口径；模型 × 档位明细的列：会话、会话 ID、模型、档位、消息数、思考 token、输入、输出、缓存写、缓存读、5h 额度%（估算）、周额度%（估算）、API 等价（美元）。
- 「成本」「API 等价」都是按官方标价折的美元，**订阅用户并不真的付这笔钱**，是拿来比大小的。会话表里的「成本口径」这一列在 0.2.0 里固定写「当前时间标签」：成本就是当前时间标签里这个会话的 API 等价金额。
- **导出的文件里有会话标题和会话 ID，别随手贴到网上。**

## 模型视图：点会话看明细

模型视图里点一个会话行，在这一行下方弹出一个小窗（再点同一行、点别处、按 Esc 或点「×」都会收起）：

- **各档位汇总**：这个会话在当前时间标签里，每个「模型 × 档位」一行：消息数、输入、输出、思考、缓存写、缓存读、5h 估算、周估算、API 等价，最后一行合计。
- **切换记录**：按时间先后，每一段（中间没换过模型和档位）一行，带起止时间和用量，所以能看到会话中途从哪个模型 / 档位切到了哪个（子任务单独标「子任务」）。段数太多时只列最近的，写明更早的几段没有列出。
- 两个按钮：「会话明细」（打开这个会话的明细窗口）、「复制为文本」（制表符分隔，粘进表格或笔记里；**里面有会话标题**）。

行首的 ▾ 表示这个会话在这段时间里换过模型或档位。

## 趋势视图

一张柱状图：「24 小时」= 最近 24 小时每小时用掉了多少 5 小时额度；「7 天」= 最近 7 天每天用掉了多少每周额度（右上角切换，记在 `trendr=`）。

- 每根柱子按**当时那个账号:计划**的系数折算；中途换过账号 / 套餐的地方画一条虚线并标出。
- 虚线 = "刚好撑满整个额度窗口"的速度（5 小时额度 20 %/小时；每周额度约 14.3 %/天）；柱子高过它（红色）= 那一段的强度如果持续一个窗口，就会把额度用光。
- 底下是合计（折合几个 5 小时窗口，或每周额度的百分之几）、API 等价金额、峰值和活跃小时 / 天的平均。没有可靠系数的记录会被排除并注明条数。
- 超过 3 小时的数据来自日志里最近 8 天的记录，需要开着「速度历史读取」（推荐、全开档默认开）。
- 鼠标停在柱子上能看到那一格的数字。

## 周报

把一周（周一 0 点到周日 24 点，本地时间）的用量整理成一个 HTML 文件，双击用浏览器打开，**不联网、不引用外部资源**。

内容：概览（这一周的 API 等价金额及较上周的变化、折合的 5 小时额度窗口个数和每周额度百分点、token 和消息数、活跃会话数和活跃小时、最烧的一小时）、每天一行的表、**每小时热力图**、模型 × 档位表、**最烧额度的前 10 个会话**（含标题和起止时间）、缓存过期后重新载入的估算、估算系数（实测还是推算）、账号 / 套餐切换记录。

- **自动**：「每周自动小结」开着时（推荐、全开档默认开；精简档关），程序运行期间每小时看一次：上一个完整的一周还没有周报，就在后台生成一份，并弹一条通知，点通知打开。生成的条件是：上周的周报文件还不存在，用量日志（`用量明细_v2.csv`）存在，并且它最后一次写入的时间不早于上周一。所以一般是每周一起、程序第一次运行时生成上周的；刚装好的头一次也会补一份。程序不检查上周是不是真的有用量，日志在上周一之后写过就会生成。暂停后台读取时不生成。
- **手动**：右键 → 周报 → 生成并打开本周小结（到现在为止）/ 生成并打开上周小结 / 打开周报文件夹。手动生成不受上面那个开关影响。
- 文件在 `%APPDATA%\Stilla\logs\周报\周报_<周一日期>.html`，同一周再生成会覆盖。
- 周报读的是 `logs\` 里的用量日志（`用量明细_v2.csv` 等），所以要开着「记录用量到日志」；金额和额度折算同样依赖额度换算表（没有时这些数字是 0 或「没有系数」的提示）。
- **周报里有会话标题和账号编号，发给别人之前先看一遍。**

## 估算自检

额度换算是估算，这个功能用来看估算靠不靠谱：拿「额度读数涨了多少」去核对「按系数估算涨了多少」。读数是服务器给的真值（整数百分比），估算是程序用价格 × 系数折的。

- **会话视图的合计行**里有一个小提示：「估算✓吻合」、「估算偏高 N×」或「估算偏低 N×」。判断用的是「估算涨幅 ÷ 读数涨幅」：在 0.72 ~ 1.35 之间算吻合（详情窗口里写作「差在 ±30% 以内」，是同一个意思的取整说法），高于 1.35 算偏高，低于 0.72 算偏低。偏差大的时候，最下面一行会换成一句警告。点提示，或右键 → 估算自检详情…，打开详情：口径（账号:计划）、系数是实测还是推算、事前预测误差、核对窗口里读数涨了多少 / 估算涨了多少、可能的原因。
- 偏高多半是系数是推算的 / 刚换了套餐或账号；偏低多半是同一个账号在网页、手机、别的电脑上也在用额度（本机记录不到）。
- 近 2.5 小时里 5 小时额度读数涨幅太小（不足 6 个点）时没法核对，会写明原因。
- 开关有两处：「功能与显示设置…」→ 后台功能 →「估算健康度自检」，和 → 其他显示内容 →「合计行里的估算自检提示」。
- 「估算误差≈N%」是另一回事：额度换算自己的"事前预测"误差（每块数据先用它之前的数据拟合、再去预测它），只显示在**模型视图和对比视图**的合计行里（会话视图的合计行里是上面的自检小提示，不是它）。

## 功能与显示设置、三档调度、暂停后台读取

**右键 → 功能与显示设置…** 一个对话框管所有开关：

- 上面是**调度策略**：全开 / 推荐 / 精简 / 自定义。点一个就按它重设下面所有选项（右键 → 调度策略 里也能直接选前三个）。你改了下面任何一项，档位就自动变成「自定义」；改到和某个档位完全一样，会自动认成那一档。
- **后台功能**（8 项，关掉能省资源）：缓存到期提醒、速度历史读取、额度换算自动重算（后台跑 Python）、VS Code 会话标题同步（后台跑 Python，每 10 分钟）、估算健康度自检、每周自动小结、把用量记录到日志文件、占用过大时自动回收内存。
- **面板里显示哪些视图**（6 个）、**会话视图里显示哪些列**（7 列）、**其他显示内容**（5 项：触顶预测、DeepSeek 费用估算行、账号小标签、↗ 跳转、估算自检提示）。至少要留一个视图、一列。

三档的区别：

| | 全开 | 推荐（新装默认） | 精简 |
|---|---|---|---|
| 后台功能 | 8 项全开 | 8 项全开 | 只留缓存到期提醒、记录用量到日志、占用过大时回收内存 |
| 视图 | 会话 模型 对比 订阅 API 趋势 | 会话 模型 对比 订阅 趋势（隐藏 API） | 会话 模型 |
| 会话列 | 全部 7 列 | 隐藏「输入」 | 缓存剩余 速度 输出 占用 |
| 其他显示 | 5 项全开 | 触顶预测、账号小标签、↗、估算自检提示（隐藏 DeepSeek 费用行） | 触顶预测、账号小标签 |
| 后台节奏 | 最勤 | 适中 | 最省，适合玩游戏或电脑吃紧的时候 |

后台节奏（0.2.0 的数值，「自定义」档用推荐档的）：面板关着时跟踪会话状态的间隔 15 / 15 / 30 秒；重读日志历史的间隔 3 / 5 / 15 分钟；额度换算自动重算的间隔 30 / 60 / 180 分钟（系数还是推算的时候 5 / 10 / 30 分钟，好尽快换成实测的）。

**暂停后台读取（打游戏用）**：右键菜单、托盘菜单、「⋮」菜单里都有，或者点面板上出现的「⏸ 后台读取已暂停（点这里恢复）」（窗口窄的时候缩成「⏸ 已暂停」）。暂停期间：不读会话记录（面板不更新，「记录用量到日志」的那个后台线程也不读）、不做缓存提醒和邮件提醒、不跑 VS Code 标题同步和额度换算重算、不生成周报。**额度读数、更新检查照常。** 这个开关不保存，重启后恢复；恢复时马上补读一次，日志也会在恢复后的下一轮把暂停期间新增的部分补上。

> 暂停期间日志停止更新，所以周报、趋势和历史里暂停的那段时间要等恢复后才补齐。

## 悬停说明

鼠标在悬浮窗里的某个东西上停约半秒，旁边会弹出一小块说明：这是什么、怎么算的、点了会怎样（缓存状态的颜色、速度和占用的算法、触顶预测怎么读、每一列的含义等等）。点一下就收起；一直停着，约 25 秒后也会收起。说明小窗不抢焦点、不挡鼠标。

默认开。开关：右键 →「悬停说明（鼠标停一会儿显示解释）」，或「⋮」菜单里同名的一项；对应 `settings.txt` 的 `tips=`。

## 时间标签条右边的「⋮」菜单

点时间标签条最右边的「⋮」（三个竖点）弹出一个菜单，下面这些设置都在里面：

- **显示哪些时间标签**：勾选 = 显示，点一下立即生效，菜单不关；恢复默认时间标签。
- **时间标签预设**：日常（15 分钟 / 本 5 小时 / 今天）、复盘（今天 / 昨天 / 本周）、精简（本 5 小时 / 今天）、默认、全部 11 个；还可以「把现在显示的标签存为我的预设」，存好后多出一项「我的预设」。
- **自定义时段**：设置自定义时段…；最近存的最多 5 个**常用时段**，一点就切过去；把当前自定义时段存为常用；清空常用时段。
- **速度统计窗口**：近 5 / 15 / 30 分钟、1 / 3 / 6 / 24 / 48 小时，或自定义…（见前面）。
- **窗口大小**：紧凑（最窄，放不下全部列时自动缩小）/ 标准（刚好放下 7 列）/ 宽屏（宽松，多显示几行）/ 高（标准宽度，多显示 18 行）。点一下套用，会自动打开用量面板。
- **显示哪些视图 / 会话视图的列 / 其他显示内容**：和「功能与显示设置…」里是同一组开关，这里点一下就生效。
- **行距**：紧凑 / 标准 / 舒适 / 宽松 / 很宽松，也可以直接拖「合计」上面那条线。
- **暂停后台读取**、**悬停说明**。
- **提醒设置**：缓存快过期时系统提醒的提前量、额度触顶预警、邮件提醒…（见前面各节）。
- **导出当前时间标签的数据**（见「排序和导出」）。
- 调度策略、功能与显示设置…、估算自检详情…、周报：和右键菜单里的一样。

## 额度换算（可选，需要 Python）

额度消耗 ≈ 按官方价格折算的美元数 × 每美元消耗的额度百分点。系数由 `scripts\quota_fit.py` 用你自己的额度快照和用量日志反推（后台低优先级运行，间隔见上面的调度策略），按"账号:计划"分开拟合。数据不够（需要几天、跨多个 5 小时窗口）时显示「—」，数字前面的「≈」表示是按官方价格推算的、没有实测。

这些数字是**估算**，不是账单。额度读数是整数百分比，同一账号在网页 / 手机 / 别的电脑上用掉的额度本机记录不到。

结果写在 `logs\额度换算.csv`，里面也有程序用来算 API 等价金额的价格表；**没有这张表时，速度、占用、触顶预测、API 等价金额、估算自检、周报里的金额都显示「—」或 0**，会话和 token 的统计不受影响。

## 账号与订阅

- 自动识别当前登录的账号和套餐（读 `.credentials.json` 里的组织 ID / 套餐，和 `.claude.json` 里的账号信息，**只存打码邮箱**）；换账号时自动切换，托盘弹提示。

## settings.txt 里可以手动改的键

`%APPDATA%\Stilla\settings.txt` 是一行一个 `键=整数` 的文本文件。一般用界面改就行；要手动改的话，**先退出 Stilla**（程序运行中会反复改写这个文件），无法识别或超出范围的值会被忽略。

| 键 | 含义 | 取值 / 默认 |
|---|---|---|
| `usage` | 用量面板：1 = 详细模式，0 = 简洁模式 | 默认 1 |
| `src` / `onl` | 额度数据来源 / 是否同意在线查询 | 见 README；默认 `src` = 自动 |
| `upd` | 启动时检查更新 | 默认 1 |
| `log` | 记录用量到日志 | 默认 1（有 `fmask` 时以 `fmask` 为准） |
| `alert` | 缓存快过期时系统提醒 | 默认 1（有 `fmask` 时以 `fmask` 为准） |
| `alertmin` | 系统提醒的提前量（分钟） | 1 ~ 120，默认 10；菜单里给的是 5 / 10 / 15 / 20 / 30 |
| `limitwarn` | 额度触顶预警（用到多少 % 通知） | 0 ~ 100，默认 90；0 = 关 |
| `speedwin` | 速度 / 占用统计窗口（分钟） | 1 ~ 2880，默认 15 |
| `tips` | 悬停说明 | 默认 1 |
| `view` | 当前视图 | 0 会话 · 1 模型 · 2 对比 · 3 订阅 · 4 API · 5 趋势 |
| `trendr` | 趋势视图的范围 | 0 = 24 小时，1 = 7 天 |
| `sort0` `sort1` `sort2` | 会话 / 模型 / 对比视图的排序 | 0 = 默认顺序；其他值是程序编码的，建议在界面里点 |
| `rowh` | 表格行距 | 14 ~ 40，默认 16 |
| `tabs` | 显示哪些时间标签（位掩码，第 i 位 = 第 i 个标签，顺序：5 分钟 15 分钟 30 分钟 1 小时 3 小时 本 5 小时 上 5 小时 今天 昨天 本周 自定义） | 默认 1258 |
| `tabpreset` | 「我的预设」的时间标签位掩码 | 0 = 还没存过 |
| `fmask` | 后台功能（位掩码）：1 缓存到期提醒 · 2 速度历史读取 · 4 额度换算自动重算 · 8 VS Code 标题同步 · 16 估算健康度自检 · 32 每周自动小结 · 64 记录用量到日志 · 128 占用过大时回收内存 | 全开 / 推荐 255，精简 193 |
| `vmask` | 显示哪些视图：1 会话 · 2 模型 · 4 对比 · 8 订阅 · 16 API · 32 趋势 | 全开 63，推荐 47，精简 3 |
| `smask` | 会话视图的列：1 缓存剩余 · 2 速度 · 4 输入 · 8 输出 · 16 缓存写 · 32 缓存读 · 64 占用 | 全开 127，推荐 123，精简 75 |
| `dmask` | 其他显示内容：1 触顶预测 · 2 DeepSeek 费用行 · 4 账号小标签 · 8 ↗ 跳转 · 16 估算自检提示 | 全开 31，推荐 29，精简 5 |

## 命令行参数

- `Stilla.exe --demo`：演示模式（假额度，设置放在临时文件夹，不碰真实设置，不检查更新），截图 / 测试用。
- `Stilla.Statusline.exe [--quiet] [--chain "命令" | --chain-file 文件]`：给 Claude Code 的 `statusLine` 用。排查问题：设环境变量 `STILLA_DEBUG=1`，错误会写到 stderr。

## 升级到 0.2.0

直接运行新版安装包（或解压新版 zip 覆盖旧文件）即可：安装程序会先关掉正在运行的 Stilla，只替换程序文件，不动 `%APPDATA%\Stilla` 里的设置和历史记录；便携版保留旁边的 `data` 文件夹。额度来源、风格、透明度、时间标签、记录用量等旧设置都会沿用。

会变的地方：

- **视图重新编号**：0.1.x 的五个视图是 会话 · 模型 · 对比 · 档位 · 订阅，0.2.0 是 会话 · 模型 · 对比 · 订阅 · API · 趋势。「档位」视图并进了「对比」；你上次停在哪个视图，升级后会对应过去。
- **窗口大小只重置一次**：0.1.x 保存的窗口大小是给旧面板定的，新面板更宽，沿用会把新增的列挤没，所以升级后第一次启动恢复默认大小；之后你再拖就会记住。
- **列宽恢复默认**：0.1.x 保存的列宽不再读取（列变多了，旧比例没法对应）。
- **新装默认是「推荐」档**：功能全开，但隐藏「输入」列、API 视图和 DeepSeek 费用行。升级的人也是这个起点（0.1.x 里专门打开过「显示 DeepSeek 估价行」的人除外，见下一条）：如果想要这几样，「功能与显示设置…」里勾上，或者调度策略选「全开」。
- **右键菜单**：「显示 DeepSeek 估价行」不在右键菜单里了（0.1.x 里打开过它的人，升级后它保持打开，调度档位会显示成「自定义」；没打开过的默认隐藏），改到「功能与显示设置…」→ 其他显示内容。
- **新的后台读取**：用量面板关着时，缓存提醒也会每隔十几秒读一次会话记录新增的部分；状态灯要读 `sessions\*.json` 里的状态（约每 2 秒一次）；速度、趋势和周报会读日志最近 8 天。想要更省，选「精简」档，或在「功能与显示设置…」里关掉对应项。
- **没有变的**：状态栏取数（`Stilla.Statusline.exe`）、更新检查、捐赠入口、数据都留在本机的原则。0.2.0 新增的联网只有一处：你自己启用邮件提醒后，向你自己填的 SMTP 服务器发信（见 [PRIVACY.md](../PRIVACY.md)）。
